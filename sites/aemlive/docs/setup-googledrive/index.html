Edge delivery service will access the google drive using a registered user during preview and publishing. You can choose to either use the default helix@adobe.com user or register your own.

  • If you choose the default user, please follow the steps highlighted in the tutorial.
  • If you want to use a custom user, please read Setup Customer Google Drive
