Deprecations and Removals

Features in AEM that do not have enough use anymore, or have been replaced with better, more reliable solutions will be removed. Before these features ...

Features in AEM that do not have enough use anymore, or have been replaced with better, more reliable solutions will be removed. Before these features are removed, they are declared deprecated and we provide suggestions for possible replacements.

In the next step, Adobe posts an end-of-service date on this page. After the end-of-service date, the respective service or feature will no longer be available.

Deprecated

Custom domains without a custom CDN

Deprecation notice

We no longer accept new domains for the Bring-your-own-DNS service. Please use Adobe Managed CDN.

Folder Mapping

Deprecation notice

Please contact us if you have a use case for folder mapping. We will help to find the best solutions. Existing projects using folder mapping may need to migrate to a different solution in the future.

Scheduling

Deprecation notice

Reach out to us if you have a use case for scheduling, we will help to find the best solution. Existing projects using scheduling may need to migrate to a different solution in the future.

Removed

*.hlx.live and *.hlx.page

End-of-service

The *.hlx.* domains have been retired in favor of *.aem.* on December 18, 2025. Click above for upgrade instructions.

Note: admin.hlx.page is excluded from this retirement and will remain operational.

Cloudflare Setup (config only, no worker) for hlx.live

No longer supported

This setup is no longer supported. Please use the cloudflare worker setup instead.

Manual Forms Sheet Setup

No longer supported

This feature is retired and has been replaced by Edge Delivery Services for AEM Forms.

IDP-Based Site Authentication

No longer supported

IDP-based site authentication has been retired and replaced with token-based authentication.

AEM Sidekick v6

End-of-service

This version of the sidekick was retired on February 2, 2026. Please use the latest sidekick version instead.

File-Based Configuration

No longer supported

Transition your configuration to the configuration service with advanced features and improved inheritance management facilities.
