Getting Started with Franklin Organizer

Keep your Franklin project organized, see live content performance data and make bulk changes with Franklin Organizer.

  • Open browser to: https://experience.adobe.com/#/@adobe-corpnew/aem-pages/.
  • Sign in with your enterprise account
    • Enter your @adobe.com email
    • If you also have a type 1 account you will be taken to a screen that asks you to select an account. Choose Company or School.
  • Verify that you are on the Adobe Corp org. If you are not then select it from the org switcher (and refresh the page because of this bug). Every Adobe employee should have access to the Adobe Corp org (I think).

That’s it!

Things to try 🚀

  • Create a canvas
  • Paste in some CDN and non CDN links (non CDN links will give a warning right now but that will be changed to be less aggressive)
  • Try grouping and ungrouping pages
  • Right click any page and view its details including RUM reports. RUM should work for both CDN and non CDN urls (assuming it's enabled), for now you wil have to enter the production host for CDN urls.
  • Try updating the metadata for a page in docs/word and then reload the page in Organizer and watch the metadata, source and preview last modified dates update in the UI.
  • Try searching for a page on the canvas by typing a search query while viewing the canvas.
  • Try saving the canvas using the save button in the top right. Refreshing the page should reload the canvas in the exact same position and state.
  • Play with some of the alignment tools in the toolbar
